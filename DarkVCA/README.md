# Dark VCA

Compresor VCA VST3 (Windows / macOS) de comportamiento tipo consola SSL E, para bus y pistas.

- **Threshold**: +10 a -20 dB (la perilla gira de izquierda a derecha de +10 a -20, como en la consola).
- **Attack**: 0.1 / 0.3 / 1 / 3 / 10 / 30 ms.
- **Release**: 100 ms fijo, o **AUTO** (dependiente del programa: se suelta rápido con transitorios y lento con compresión sostenida).
- **Ratio fijo 3:1**, rodilla corta de 3 dB, detector enlazado en estéreo.
- **Makeup**: 0 a +15 dB. Botón **IN** (bypass) y escalera de LEDs de gain reduction (3 / 6 / 10 / 14 / 20 dB).

Compila automático en GitHub Actions junto con Bluey Comp (carpeta `BlueyComp`).
