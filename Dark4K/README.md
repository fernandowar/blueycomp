# Dark 4K
Channel strip estilo SSL 4000 E: EQ (HF/HMF/LMF/LF, filtros HPF/LPF, Brown/Black) a la izquierda, Dark VCA (compresor + saturación) a la derecha, fader y medidores al centro, puerta básica. Cada instancia tiene un número de canal que varía levemente la tolerancia analógica (click en CH para re-sortear).
